# 1.0.0 发布验证

## 产物

- `structure_rewind_watch-neoforge1.21.1-1.0.0.jar`：Minecraft 1.21.1，NeoForge 21.1.248，Java 21。
- `structure_rewind_watch-forge1.20.1-1.0.0.jar`：Minecraft 1.20.1，Forge 47.4.0，Java 17。

两个 JAR 都有怀表、实体恢复、回溯抑制器、权限与配置、金色钟盘和暂停/HUD 修复。只安装与游戏环境对应的一份。

## 验证记录

NeoForge 与 Forge 两端均完成：

- Gradle 构建成功；Forge JAR 执行 `reobfJar` 并包含生产环境需要的 refmap。
- 普通 GameTest 环境：8 项全部通过。
- 模拟已有 `LevelChunk.markPosForPostprocessing` 方法的兼容环境：8 项全部通过。
- 客户端启动到资源加载成功，无模组 Mixin 应用失败、缺失模型或贴图错误。
- 检查 JAR 内版本号 1.0.0、Java 字节码版本（65 / 61）、数据包目录规范及发布包不包含测试类。

测试涵盖：结构搜索距离、正则名单、地下宝箱/结构恢复、普通冷却/OP 使用、模板实体恢复和重复回溯、宠物与生成失败保护、抑制器范围/所有权/取消回溯，以及指针五秒后继续转动、暂停时钟和渐隐。

这不等同于在用户完整整合包中逐个检查第三方 HUD，或完成真实多人联网验收。客户端加载检查也不代替动画观感的人工验收。

## 分支与构建

- `main`：NeoForge 1.21.1。
- `1.20.1`：Forge 1.20.1 / 47.4.0。

分别在对应分支运行 `./gradlew build`。发布说明见 `docs/模组介绍.md`。

Forge 的 SERVER 配置位于存档 `serverconfig/structure_rewind_watch-server.toml`，NeoForge 本项目版本默认在 `config/structure_rewind_watch-server.toml`（以实际日志输出为准）。配置项含义相同。
