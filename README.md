# 结构回溯怀表 / Structure Rewind Watch

作者：**P1nero**。Minecraft **1.21.1**，NeoForge **21.1.248+（21.1.x）**，Java **21**。服务端和客户端都安装本模组。

手持怀表右键，选择玩家所在结构或距离其包围盒不超过 10 格的最近允许结构。播放约 5 秒的金白钟盘、逆转双指针、环形辉光、星点与音效，随后在黑屏下分批恢复结构；服务器完成后发送结束消息，画面渐隐。默认距离结构 64 格内的玩家一同观看。

物品不消耗，成功完成后通过原版物品冷却系统冷却 20 分钟。OP 权限等级 2 及以上跳过冷却，但仍受黑白名单和任务互斥限制。一次只处理一个结构；没有可用结构、结构过大或准备失败时不收取冷却。

获取：创造模式「工具与实用物品」，或：

```mcfunction
/give @s structure_rewind_watch:structure_rewind_watch
```

使用用户提供的 `怀表.png` 原图，包含中文及英文名称、Tooltip 和反馈信息。未额外指定合成配方。

## 配置

首次运行服务器或进入单人存档后生成 `config/structure_rewind_watch-server.toml`（NeoForge SERVER 配置；实际位置也会在日志中打印）。示例见 [examples/structure_rewind_watch-server.toml](examples/structure_rewind_watch-server.toml)。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `cooldownSeconds` | 1200 | 成功后冷却秒数，0 为无冷却 |
| `searchRadius` | 10 | 玩家方块坐标到结构包围盒的三维距离，单位格 |
| `effectRadius` | 64 | 特效观众到结构包围盒的距离，单位格；使用者总会收到特效 |
| `chunksPerTick` | 1 | 每个服务端 tick 重放的区块数 |
| `maxStructureChunks` | 1024 | 允许重置的结构包围盒最大区块数 |
| `structureWhitelist` | `[]` | 结构 ID 正则白名单；空表示全部允许 |
| `structureBlacklist` | `[]` | 结构 ID 正则黑名单；优先于白名单 |

列表使用 **Java 正则完整匹配**，针对结构注册 ID，而非显示名称或结构标签。例如：

```toml
structureWhitelist = ["minecraft:.*", "your_mod:.*dungeon.*"]
structureBlacklist = ["minecraft:(stronghold|fortress)"]
```

冷却沿用 Minecraft 原生规则，按游戏 tick 计时，不是离线墙钟计时，也不额外持久化原版冷却。配置搜索半径只决定目标选择；被选中后恢复整个结构，不截断为半径 10 格的小区域。

## 恢复范围与实现

根据存档中已有的 `StructureStart`/部件 NBT 复制原布局，重置原版神庙宝箱、陷阱、刷怪笼等一次性生成标记，再逐区块调用 `placeInChunk`、处理方块后处理并同步区块。不会重新抽取拼图结构布局。模板部件锚点被保留，避免部分结构在再次放置时漂移。实体按生成位置、类型及持久化来源标记匹配；不再用整个区域的同类数量抵扣。回溯时临时加载目标区块，等待实体数据就绪后再恢复。

这是**按结构生成规则重放**，并非整个区域的历史快照：生成规则覆盖的方块、宝箱内容和机关会恢复；未被生成器写入的位置和整个地形不会整体清空或回滚。玩家建筑若位于结构写入位置也会被覆盖。手工建筑、普通地牢 feature 和只有 `/place structure` 方块但没有存档结构引用的区域，不属于可查找的世界生成结构。不会为搜索生成未探索的区块。

第三方结构的自定义生成标记、处理器和实体行为可能需要额外兼容；自动化集成测试覆盖原版沙漠神殿及包含实体的测试模板。大型部件单个区块仍可能产生耗时，`chunksPerTick` 和黑名单可用于控制服务器负载。异常时会释放任务、结束过渡并记录日志，已写入区块不会自动回滚。

实现思路参考 [someaddons/respawningstructures 的 neo1.21 分支](https://github.com/someaddons/respawningstructures/tree/neo1.21)，没有增加该模组依赖。视觉主题参考 [《波斯王子：时之砂》的时间回溯设定](https://www.ubisoft.com/en-au/games/prince-of-persia-the-sands-of-time)，钟盘动画使用原创程序绘制，没有使用游戏美术或音频素材；音效使用 Minecraft 内置声音。

## 构建与验证

```sh
./gradlew build
./gradlew runGameTestServer
./gradlew runClient
```

输出：`build/libs/structure_rewind_watch-neoforge1.21.1-1.0.0.jar`。

开发专用 GameTest 位于 `src/gameTest`，不会打包进发布 jar。测试覆盖：三维搜索距离与边界、正则名单优先级和无效表达式、神殿方块恢复、动画前不提前恢复、地下宝箱战利品重置、普通玩家冷却以及 OP 再次回溯。

客户端启动与资源加载已验证。钟盘的实际屏幕观感及多名真实客户端同步仍需在游戏中人工验收。

## 1.0.2 指针与实体恢复

针身、箭头和刻度线改为沿中轴对称绘制，箭头尖端与针身中线对齐。

新增配置（默认均为 `true`）：

| 配置项 | 作用 |
| --- | --- |
| `restoreTemplateEntities` | 回溯期间恢复结构模板 NBT 中保存的实体，即使其放置设置原本忽略实体；不改变正常世界生成 |
| `resetExistingStructureEntities` | 将匹配到的旧结构实体替换为重新生成的初始状态；设为 false 时仅补回缺失实体 |

恢复的实体带有持久化结构来源和出生位置标记；再次回溯时可匹配仍在结构包围盒外扩 16 格内的已移动实体。旧实体没有来源标记时，只匹配出生点 0.75 格内、同类型且同名称的实体。这是兼顾旧存档的近距离推断，不能完美区分恰好位于同一位置的玩家摆放实体；未标记且已远离出生点的旧实体也无法可靠识别。玩家、已驯服/有主生物、正在骑乘或载客的实体会受到保护。只有确认替代实体成功加入世界后才移除旧实体，避免其他模组阻止生成时误删。替换不触发死亡掉落。

仅恢复模板和结构生成逻辑实际包含的实体。脚本/任务系统额外生成的 NPC、模组自定义“只生成一次”标记、未保存到模板的生物，以及越过上述匹配范围的实体，需要结合具体模组做适配。此版本没有全局清空区域实体，也不是任意实体的历史快照恢复。

新增测试覆盖：模板忽略实体设置、附近无关同类实体、受损实体恢复、已移动/已移除实体再次恢复、重复回溯不增殖、宠物保护、生成失败保留旧实体，以及仅补缺失实体配置。常规环境和模拟整合包同名方法冲突环境均运行 6 项 GameTest。

## 回溯抑制器（1.1.0）

新方块及方块物品：`structure_rewind_watch:rewind_inhibitor`，创造模式「工具与实用物品」。

```mcfunction
/give @s structure_rewind_watch:rewind_inhibitor
```

金色四边雕饰、全透明中心；六面共用 64×64 RGBA 像素贴图，中心显示发光的自转怀表物品模型。方块有完整碰撞体，亮度 10。方块物品 Tooltip 包含作用范围、所有权和生效条件，中英双语。

服务器配置：`inhibitorRadius = 100`，范围 1–512 格。以方块中心到玩家位置的三维球形距离计算，边界包含在内。所有玩家（包括摆放者和管理员）均禁止激活怀表；已经开始的回溯在收到抑制状态后停止后续写入，已经写入的区块不会倒退。

权限：记录实际摆放玩家 UUID 并持久化。只有摆放者或权限等级 2+ 的管理员能拆除，创造模式也受限制。无主人方块（例如命令放置）由管理员拆除。正常拆除掉落方块物品，重新摆放绑定新摆放者。禁止活塞搬移、爆炸和实体破坏；结构回溯不会覆盖此方块。管理员世界编辑命令和绕过标准 Minecraft 事件的第三方工具不受一般挖掘事件限制。

性能：只有服务端有方块实体 ticker，无客户端 tick。首次 tick/摆放时通知一次，此后每 20 tick 只遍历同维度玩家，按坐标将通知错开；不搜索区块、方块或全部方块实体。通知写入服务器玩家缓存，不产生每秒网络广播。使用怀表时只检查缓存中已知来源的坐标，不为查询加载区块；再次核对距离、方块是否还存在及 40 tick 缓存有效期。离开范围或拆除即时失效，新进入范围最多延迟 20 tick。多个抑制器独立生效，断线/换维度清理玩家缓存。每个玩家至多每 40 tick 因通知进行一次过期清理，避免密集摆放产生反复全缓存清理。

未加载/不 tick 的区块中的抑制器不会持续广播，模组不会强制加载其区块。缓存过期后失效。中心物品仅在 48 格内渲染，纹理静态且不为每个方块分配动画资源。

贴图：`src/main/resources/assets/structure_rewind_watch/textures/block/rewind_inhibitor.png`，可用 `python3 tools/draw_inhibitor_texture.py` 重新绘制（需要 Pillow）。曾尝试内置 image_gen 生成透明金边，但工具未返回文件；最终资源为确定性的手工像素绘制，没有调用外部生成 API。原始美术要求：正交方形像素金色雕饰边框、四角菱形装饰、古代时间圣物风格、中心真正透明、无文字。

新增抑制器 GameTest，并在神殿集成测试中验证激活阻止和吟唱取消；普通/模拟整合包冲突环境各 7 项测试。客户端资源加载与实际多人游戏中的外观验收是不同检查，完整整合包仍需实际安装验证。
